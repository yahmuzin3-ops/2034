# Rise of Champions (Fencing)

펜싱 선수를 키워서 클럽 대회부터 한국 선수권, 세계 선수권, 올림픽까지 도전하는 자바 Swing 게임이에요.

## 실행

```bash
javac -encoding UTF-8 *.java
java Main
```

자바 11 이상이면 돼요. 모든 `.java`는 `src` 폴더 바로 아래에 있어야 해요(패키지 없음). 저장 파일은 실행 폴더의 `savegame.dat`이고, 예전 저장 파일도 불러와져요.

## 경기 규칙 (실제 펜싱 규칙 기반)

- **개인전(선수 1명)**: 15점 선취, 3분 × 3피리어드, 동점이면 서든데스(우선권 추첨 후 1분)
- **단체전(선수 2~3명)**: 릴레이. 3명이면 공식 순서대로 9경기 45점, 경기당 3분, 점수는 팀 전체로 누적
- **매 구간 전술 선택**: 공격 / 페인트 / 방어·리포스트 / 반격 / 전진 / 후퇴를 두 선수가 동시에 골라서 한꺼번에 공개해요. 4번 연속 후퇴하면 후방 라인 이탈로 실점해요.
- **종목별 규칙**
  - 플뢰레: 몸통만 유효, 우선권 있음, 방어 후 리포스트와 페인트가 강해요.
  - 에페: 전신 유효, 우선권 없음, 동시타(양쪽 득점), 반격(스톱히트)이 강해요.
  - 사브르: 허리 위 유효, 우선권 있음, 속공이 빠르지만 방어와 후퇴가 약해요.
- **체력(지구력)**: 전술마다 체력을 써요. 낮으면 성공률이 최대 18% 떨어져요. 휴식 시간에만 아이템을 쓸 수 있어요.
- **날씨와 장비**: 맑음/흐림/비/무더위가 경기에 영향을 주고, 논슬립 신발·쿨링 재킷으로 막을 수 있어요.

## 대회

| 대회 | 방식 | 출전 조건 |
|---|---|---|
| 클럽 · 도 대회 | 단판 경기 (결승전 보스전 있음) | 종목별 승리 수 |
| **자국 선수권** (한국 선수권 등) | 토너먼트: 예선 풀(5점 경기) → 본선 8강 | 해당 종목 8승 |
| **세계 선수권** | 토너먼트: 예선 풀 → 본선 16강 | 해당 종목 20승 |
| **올림픽** | 토너먼트: 시드 순 16강 → 동메달 결정전 | 해당 종목 30승 + 파워 랭킹 8위 이내 |

- 자국 선수권·세계 선수권·올림픽은 **시즌 캘린더의 대회 기간**에만 출전할 수 있고, 한 대회에는 종목마다 한 번만 나갈 수 있어요.
- 토너먼트는 **다음 경기를 직접 하거나 시뮬레이션**하거나, 대회를 포기할 수 있어요. 직접 하지 않은 경기는 파워 레이팅으로 결과가 정해져요.
- 예선 풀은 레이팅 순으로 뱀 모양 시드를 배정하고, 풀 성적(승수 → 득실 차 → 득점)이 본선 시드가 돼요. 본선은 1·2번 시드가 결승에서만 만나는 표준 대진이에요.
- 단체전 토너먼트는 7개 팀과 겨루는 8팀 토너먼트예요. 세계 선수권·올림픽은 각국 대표팀이 나와요.
- 금·은·동메달을 따면 보상과 경험치를 받고 **시상식**이 열려요. 메달 기록은 파워 랭킹 화면에서 볼 수 있어요.

## 사용하기 편하게

- **오늘의 추천**: 홈 화면에서 지금 하면 좋은 일을 급한 순으로 보여주고, 버튼 하나로 해당 화면으로 이동해요. (부상·지침·배고픔, 대회 개막, 해금까지 남은 승리, 주급 걱정, 올림픽 출전선, 스태프, 의뢰 등)
- **선수 컨디션 카드**: 선수마다 체력·피로·배고픔·기분 막대와 상태(대기·훈련 중·부상...)를 한눈에 보여줘요. 누르면 선수 관리로 이동해요.
- **메뉴 알림 표시**: 대회가 열렸거나 급한 일이 있으면 왼쪽 메뉴 이름 옆에 ● 또는 ! 가 붙어요.
- **도움말**: 모든 화면 제목 줄의 `? 도움말` 버튼(또는 F1)이 그 화면에 맞는 탭을 열어요. (처음 시작하기 / 경기 방법 / 대회와 시즌 / 파워 랭킹 / 코치·스태프 / 단축키) 새 게임을 시작하면 처음 한 번 자동으로 열려요.
- **저장**: 3분마다, 그리고 대회가 끝날 때마다 `autosave.dat`에 자동 저장해요. 다시 시작하면 가장 최근 저장(직접 저장 또는 자동 저장)을 설명과 함께 이어서 할 수 있어요. 저장은 임시 파일에 먼저 쓰고 바꿔치기해서 저장 도중 꺼져도 파일이 깨지지 않아요. 종료 창은 `저장하고 종료 / 저장 안 하고 종료 / 취소`로 나와요.
- **키보드**: 경기 중 `1~6` 전술 선택, `Space`/`Enter` 계속하기 · `F1` 도움말 · `Ctrl+S` 저장 · `Alt+1~9` 왼쪽 메뉴 이동
- **대회 편의**: 대회 화면에 `끝까지 시뮬레이션` 버튼이 생겼고, 버튼마다 마우스를 올리면 설명이 나와요. 경기를 마친 뒤에는 결과 창에서 승리 세리머니를 볼 수 있어요.

## 소속 국가

- 새 게임을 시작할 때 **소속 국가를 고를 수 있어요**(한국 포함 16개국). 파워 랭킹 화면의 **소속 국가 변경** 버튼으로 언제든 바꿀 수 있고, 창을 닫으면 한국이에요.
- 소속 국가에 따라 **자국 선수권**이 그 나라 이름(예: 프랑스 선수권)으로 바뀌고, 그 나라 선수들끼리 겨뤄요. 랭킹의 "국내 순위", "자국 선수만 보기"도 소속 국가 기준이에요.
- 세계 선수권·올림픽 단체전에서는 소속 국가를 뺀 각국 대표팀과 겨루고, 내 팀은 소속 국가를 대표해요.
- 나라마다 펜싱 수준이 달라서 **자국 선수권 난이도가 달라져요**. 한국·캐나다는 쉬운 편이고, 프랑스·이탈리아·미국·헝가리·중국·우크라이나는 어려워요. (Lv12 선수가 자국 선수권에서 메달을 딸 확률: 한국 약 70%, 일본 약 60%, 프랑스 약 17%)
- 예전 저장 파일은 한국 소속으로 불러와져요.

## 시즌 캘린더

- 1시즌은 120일(10일씩 12달)이에요. **자국 선수권**은 시즌마다 2번(20일째·80일째부터 8일간), **세계 선수권**은 시즌마다 1번(50일째부터 10일간), **올림픽**은 4시즌에 한 번(100일째부터 15일간) 열려요. 동네 클럽·도 대회는 언제든 열려 있어요.
- 캘린더 화면에서 한 해 막대와 오늘 위치, 다가오는 대회, 내 종목별 출전 가능 여부, 시즌별 메달 성적과 포인트(금 10·은 6·동 4, 세계 선수권 x2, 올림픽 x3)를 볼 수 있어요.
- 대회가 개막하거나 3일 전이 되면 화면 위에 알림이 떠요.

## 코치 · 스태프

역할마다 한 명씩 고용하고, 레벨(1~5)이 높을수록 효과가 크고 주급도 높아요. 주급은 7일마다 나가고, 골드가 모자라면 주급이 높은 스태프부터 떠나요. 영입 후보는 14일마다 바뀌고, 승급도 할 수 있어요.

| 역할 | 효과 |
|---|---|
| 수석 코치 | 훈련 효율 +4%/레벨 |
| 트레이너 | 휴식 회복 +2/레벨, 대회 경기 사이 회복 +3/레벨, 무리해서 뛴 선수의 부상 확률 -2%p/레벨 |
| 전력 분석관 | Lv2부터 상대의 전술 비율을, Lv4부터 최근 5번 중 가장 많이 쓴 전술(다음 선택 예상)을 알려 줘요 |
| 영양사 | 식단 효과 +10%/레벨 |

## 기록실

- **트로피 룸**: 딴 메달과 우승컵을 진열장에 걸어요(마우스를 올리면 대회·날짜가 나와요). 메달마다 그때의 소속 국기가 붙고, 달성한 업적은 명패로 걸려요.
- **라이벌**: 대회 개인전에서 만난 컴퓨터 선수와의 상대 전적(승패, 득실, 연승·연패, 마지막 경기, 현재 레이팅)이 쌓여요. 3경기 이상이면 라이벌, 앞서 지는 상대는 천적이에요. 지난번에 진 상대가 다시 대회에 나오면 복수전 알림이 떠요.
- **경기 통계**: 최근 400경기의 승률·연승, 최근 20경기 점수 차 그래프, 전술 사용 비율과 득점 성공률, 종목별·대회별 전적, 득점 방식(리포스트·동시타·후방 이탈), 선수별 득실을 볼 수 있어요.

## 국기

16개국 국기를 코드로 그려요(이미지 파일 필요 없음). 소속 국가 선택 창, 상단 바, 랭킹 표, 대진표, 경기 점수판, 시상식 시상대와 깃대(금메달이면 국기가 올라가요), 라이벌 표, 트로피 룸에 나와요.

## 파워 랭킹

- 종목별로 한국·세계 선수 약 140명과 내 선수가 레이팅으로 순위가 매겨져요. (Elo 방식)
- 내 선수의 레이팅은 **능력치(장비 포함)** 로 정해지는 기본 점수에 경기 결과 보정이 더해져요. 훈련하면 바로 오르고, 센 상대를 이기면 더 많이 올라요.
- 레벨 1칸의 점수 차(48점)는 실제 경기 엔진의 승률을 측정해서 맞췄어요.
- 컴퓨터 선수들도 훈련하고 경기를 치르며 시간이 지나면 조금씩 강해져요. 주간 변동(▲▼)이 표시돼요.
- 등급: 입문 → 아마추어 → 유망주 → 프로 → 엘리트 → 월드클래스 → 전설

## 육성 · 경제

- **선수**: 종목(플뢰레/에페/사브르), 성향 4종(열정형 공격 +3, 신중형 기술 +3, 느긋형 최대 HP +20, 승부욕형 민첩 +3), 능력치(HP·공격·방어·민첩·기술), 상태(배고픔·피로·기분·부상)
- **훈련 5종**: 풋워크 / 블레이드워크 / 근력 / 파라드(방어) / 지구력. 시간이 걸리는 훈련이고 훈련마다 레벨이 올라가요.
- **자율 행동**: 훈련·시합 중이 아닌 선수는 상태를 보고 스스로 휴식 → 식사 → 기분 전환 → 섀도 펜싱을 해요. 선수마다 켜고 끌 수 있어요.
- **장비**: 블레이드 / 그립 / 마스크 / 펜싱화 / 재킷. 낀 장비가 선수 그림에 그대로 나타나고, 날씨 대응 장비(논슬립 신발, 쿨링 재킷)가 있어요.
- **경제와 목표**: 경기 보상·후원금, 상점 구매/판매, 선수 영입, 시설 업그레이드, 의뢰와 업적, 날씨·부상·후원 같은 이벤트

## 연출

- 득점하면 선수가 검을 높이 들고 **세리머니**를 하고, 경기에서 이기면 승리 포즈와 색종이가 나와요. 지면 고개를 떨궈요.
- 업적·의뢰 달성, 메달 획득은 화면 위에 **알림 팝업**이 내려왔다 올라가요.
- 효과음은 코드로 합성해서 별도 소리 파일이 필요 없어요. (홈 화면에서 끌 수 있어요.)
