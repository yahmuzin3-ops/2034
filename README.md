# Rise of Champions (Fencing)

펜싱 선수를 키워서 클럽 대회부터 한국 선수권, 세계 선수권, 올림픽까지 도전하는 자바 Swing 게임이에요.

## 실행

```bash
javac -encoding UTF-8 *.java
java Main
```

자바 11 이상이면 돼요. 모든 `.java`는 `src` 폴더 바로 아래에 있어야 해요(패키지 없음). 저장 파일은 실행 폴더의 `savegame.dat`이고, 예전 저장 파일도 불러와져요.

## 경기 규칙 (실제 펜싱 규칙 기반)

- **개인전(선수 1명)**: 15점 선취, 3분 × 3피리어드, 동점이면 서든데스(우선권 추첨 후 1분)
- **단체전(선수 2~3명)**: 릴레이. 3명이면 공식 순서대로 9경기 45점, 경기당 3분, 점수는 팀 전체로 누적
- **매 구간 전술 선택**: 공격 / 페인트 / 방어·리포스트 / 반격 / 전진 / 후퇴를 두 선수가 동시에 골라서 한꺼번에 공개해요. 4번 연속 후퇴하면 후방 라인 이탈로 실점해요.
- **종목별 규칙**
  - 플뢰레: 몸통만 유효, 우선권 있음, 방어 후 리포스트와 페인트가 강해요.
  - 에페: 전신 유효, 우선권 없음, 동시타(양쪽 득점), 반격(스톱히트)이 강해요.
  - 사브르: 허리 위 유효, 우선권 있음, 속공이 빠르지만 방어와 후퇴가 약해요.
- **체력(지구력)**: 전술마다 체력을 써요. 낮으면 성공률이 최대 18% 떨어져요. 휴식 시간에만 아이템을 쓸 수 있어요.
- **날씨와 장비**: 맑음/흐림/비/무더위가 경기에 영향을 주고, 논슬립 신발·쿨링 재킷으로 막을 수 있어요.

## 대회

| 대회 | 방식 | 출전 조건 |
|---|---|---|
| 클럽 · 도 대회 | 단판 경기 (결승전 보스전 있음) | 종목별 승리 수 |
| **한국 선수권** | 토너먼트: 예선 풀(5점 경기) → 본선 8강 | 해당 종목 8승 |
| **세계 선수권** | 토너먼트: 예선 풀 → 본선 16강 | 해당 종목 20승 |
| **올림픽** | 토너먼트: 시드 순 16강 → 동메달 결정전 | 해당 종목 30승 + 파워 랭킹 8위 이내 |

- 토너먼트는 **다음 경기를 직접 하거나 시뮬레이션**하거나, 대회를 포기할 수 있어요. 직접 하지 않은 경기는 파워 레이팅으로 결과가 정해져요.
- 예선 풀은 레이팅 순으로 뱀 모양 시드를 배정하고, 풀 성적(승수 → 득실 차 → 득점)이 본선 시드가 돼요. 본선은 1·2번 시드가 결승에서만 만나는 표준 대진이에요.
- 단체전 토너먼트는 7개 팀과 겨루는 8팀 토너먼트예요. 세계 선수권·올림픽은 각국 대표팀이 나와요.
- 금·은·동메달을 따면 보상과 경험치를 받고 **시상식**이 열려요. 메달 기록은 파워 랭킹 화면에서 볼 수 있어요.

## 파워 랭킹

- 종목별로 한국·세계 선수 약 140명과 내 선수가 레이팅으로 순위가 매겨져요. (Elo 방식)
- 내 선수의 레이팅은 **능력치(장비 포함)** 로 정해지는 기본 점수에 경기 결과 보정이 더해져요. 훈련하면 바로 오르고, 센 상대를 이기면 더 많이 올라요.
- 레벨 1칸의 점수 차(48점)는 실제 경기 엔진의 승률을 측정해서 맞췄어요.
- 컴퓨터 선수들도 훈련하고 경기를 치르며 시간이 지나면 조금씩 강해져요. 주간 변동(▲▼)이 표시돼요.
- 등급: 입문 → 아마추어 → 유망주 → 프로 → 엘리트 → 월드클래스 → 전설

## 육성 · 경제

- **선수**: 종목(플뢰레/에페/사브르), 성향 4종(열정형 공격 +3, 신중형 기술 +3, 느긋형 최대 HP +20, 승부욕형 민첩 +3), 능력치(HP·공격·방어·민첩·기술), 상태(배고픔·피로·기분·부상)
- **훈련 5종**: 풋워크 / 블레이드워크 / 근력 / 파라드(방어) / 지구력. 시간이 걸리는 훈련이고 훈련마다 레벨이 올라가요.
- **자율 행동**: 훈련·시합 중이 아닌 선수는 상태를 보고 스스로 휴식 → 식사 → 기분 전환 → 섀도 펜싱을 해요. 선수마다 켜고 끌 수 있어요.
- **장비**: 블레이드 / 그립 / 마스크 / 펜싱화 / 재킷. 낀 장비가 선수 그림에 그대로 나타나고, 날씨 대응 장비(논슬립 신발, 쿨링 재킷)가 있어요.
- **경제와 목표**: 경기 보상·후원금, 상점 구매/판매, 선수 영입, 시설 업그레이드, 의뢰와 업적, 날씨·부상·후원 같은 이벤트

## 연출

- 득점하면 선수가 검을 높이 들고 **세리머니**를 하고, 경기에서 이기면 승리 포즈와 색종이가 나와요. 지면 고개를 떨궈요.
- 업적·의뢰 달성, 메달 획득은 화면 위에 **알림 팝업**이 내려왔다 올라가요.
- 효과음은 코드로 합성해서 별도 소리 파일이 필요 없어요. (홈 화면에서 끌 수 있어요.)

## 코드 구조

| 분류 | 파일 |
|---|---|
| 경기 엔진 | `Battle`(규칙·전술), `FencingStage`(경기 장면), `FencerArt`(선수 그림·자세) |
| 대회 | `Tournament`(예선 풀·본선·동메달전), `TournamentPanel`(대진표 화면), `MedalRecord`, `CeremonyDialog`(시상식) |
| 레이팅 | `RatingSystem`, `Rival`(컴퓨터 선수), `FencingWorld`(세계·대회 명단), `RankEntry`, `RankingPanel` |
| 상태 | `GameState`, `Fencer`, `Region`, `Achievement`, `SaveManager`, `GameEngine`(시간·자율 행동) |
| 화면 | `MainFrame`, `MatchPanel`, `ToastPane`(알림), `FencerFigure`·`GearArt`(선수·장비 그림), 그 밖의 `*Panel` |
| 개발용 | `tools/` — 승률 측정(`Calib`), 토너먼트 검증(`TourTest`), 통합 테스트(`FlowTest`), 화면 렌더링(`Render`) |

개발용 도구는 프로젝트 파일을 컴파일한 뒤 `javac -cp . -d out tools/*.java`로 만들고 `java -cp out FlowTest`처럼 실행해요.
